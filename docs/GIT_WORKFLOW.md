# Работа с Git

Репозиторий: [Kolesnikovdevai/avi-platform](https://github.com/Kolesnikovdevai/avi-platform).
Основная ветка — main. Первый коммит сохраняет каркас этапа 1 до изменения дизайна.

Небольшие законченные изменения выполняются в тематической ветке, проходят локальные проверки, отправляются в origin и оформляются pull request в main. Текущая переработка интерфейса — design/light-dashboard. В PR указываются поведение, выполненные проверки и ограничения; screenshots можно прикреплять отдельно, не добавляя сгенерированные artifacts в исходники. Перед merge проверить CI и diff; merge выполняется по поручению владельца. GitHub Pages/production deployment не настраиваются автоматически.

Перед коммитом проверить git diff и staged-файлы, запустить релевантные lint/typecheck/test, сканирование секретов и audit при изменении зависимостей. .env, .tools, .local, виртуальные среды, node_modules, отчёты и дампы исключены .gitignore; .env.example содержит только заглушки. Не использовать git add -f для этих файлов. Текстовые исходники нормализуются в LF, PowerShell — CRLF по .gitattributes.

Коммиты подписываются локально настроенной идентичностью GitHub с noreply email. Пароли/токены не добавляются в URL origin или git config. Не использовать force push и не переписывать опубликованную историю для обычной работы.
