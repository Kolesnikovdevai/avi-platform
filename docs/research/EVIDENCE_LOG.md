## Попытка E001: доступ к официальной документации

- Источники: https://developers.avito.ru/ и https://developers.avito.ru/api-catalog.
- Действие: открыть обе публичные страницы инструментом веб-просмотра.
- Фактический результат: обе вернули `cannot be opened (non-retryable error)`.
- Содержимое спецификации и её версия: не получены.
- Вывод: документация **не проверена**. Ошибка инструмента не доказывает недоступность API или отсутствие возможностей у Авито.
- Авторизованные запросы: не выполнялись; доступ к разрешённому аккаунту в этой работе не установлен.
- Контракты, маршруты, scopes, TTL, лимиты, очищенные ответы: отсутствуют.
- Следующий шаг: прочитать официальный контракт через доступный канал либо предоставленный официальный экспорт; затем отдельно согласовать разрешённый сценарий проверки аккаунта. Секреты передавать только через локальное защищённое окружение, не чат/git.
